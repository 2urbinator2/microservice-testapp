# Frontend 


## How to use?
**Node.js** & **npm**: Required to install dependencies and run the local development server.

1. `npm install`
2. `npm start`
3. `http://localhost:3000/`

## Structure

**public:** Contains static assets, including the logo displayed in the browser tab

**src:** The primary directory for all source code, components, and styles.

- `components` – Reusable UI components used throughout the website.
- `design` – Specific styling and design assets for individual components.
- `pages` - Contains the main view components and page layouts.
- `pictures`
- `app` – The core component defining the primary page layout and structure.
- `index` – The entry point of the application that renders the root component.
